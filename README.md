# ¡Hola! Soy Joaquin 👋
 
## 🧑‍💻 Quién soy
Soy un desarrollador full stack y estudiante de programación (UTN), con experiencia en soporte técnico y desarrollo de software. Me enfoco en construir aplicaciones web completas, desde el diseño de la base de datos y la API hasta la interfaz de usuario, y disfruto entender cómo funcionan las tecnologías por debajo de la superficie, no solo usarlas.
 
## 🚀 Habilidades
Trabajo cómodo en todo el flujo de una aplicación: desde el modelado de datos y la lógica de negocio en el backend, hasta la construcción de interfaces responsivas en el frontend. Tengo experiencia implementando autenticación con JWT y control de acceso basado en roles (RBAC), diseñando entidades y migraciones de base de datos, y resolviendo problemas de integración con servicios externos como Cloudinary. Además, manejo Git y GitHub para trabajo colaborativo en equipo, coordinando ramas y resolviendo conflictos junto a otros desarrolladores.
 
## 🛠️ Tecnologías
Mi stack principal gira en torno a JavaScript/TypeScript tanto en el frontend como en el backend. Uso React y Next.js para construir interfaces modernas, NestJS para levantar APIs robustas y escalables, y bases de datos como PostgreSQL y MongoDB según las necesidades del proyecto, junto con Tailwind CSS para estilizar de forma rápida y consistente.
